# yugure

Yūgure (夕暮れ) — a quiet twilight dark **theme** for Inkdrop 6. A neutral
near-black ground, dimmed body text, and six muted accents with one job each.
Chrome stays close to the editor background; accents are used as text, never
as solid fills.

![Screenshot of yugure](./docs/screenshot.png)

The same palette drives the author's Neovim, tmux, Alacritty and lazygit
configs, so notes and code look alike.

## Palette

| role     | hex       | used for                                  |
| -------- | --------- | ----------------------------------------- |
| base     | `#141518` | editor background                         |
| text     | `#9DA4B2` | body text                                 |
| muted    | `#5E6577` | comments, quotes, dates                   |
| rose     | `#B98590` | keywords, list bullets, table heads, h1   |
| gold     | `#BFA077` | strings, warnings, marks, h2              |
| foam     | `#7AA3B5` | functions, links, info, h3                |
| teal     | `#7BA09F` | types, tags, inline code, additions, h4   |
| iris     | `#9A8EB9` | numbers, attributes, meta, h5             |
| love     | `#BA6B70` | errors and deletions only                 |

## Install

```sh
ipm install yugure
```

Then enable it in **Preferences → Themes**.

## Development

```sh
npm install
ipm link --dev   # symlink into your Inkdrop data dir
npx dev-server   # optional hot reload
```

- `styles/tokens.css` — generated `--hsl-*` / `--color-*` ramps plus raw
  `--yugure-*` HSL triplets. Regenerate with `npm run tokens` after editing
  the palette in `scripts/gen-tokens.py`; do not hand-edit.
- `styles/ui.css` — app chrome (sidebar, note list, menus, modals).
- `styles/syntax.css` — CodeMirror editor and Markdown source.
- `styles/preview.css` — rendered Markdown preview and Mermaid.

Yugure has six hues and Inkdrop's design tokens want seventeen families, so
each family anchors the nearest yugure accent at step 500 with lightness
interpolated. No extra colours are invented: a new colour is a new role, not a
new shade.

`palette.json` is a snapshot of the resolved variables used for theme
previews. It is regenerated by `ipm publish` via `prepublishOnly`.
